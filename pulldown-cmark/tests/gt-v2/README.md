# GT-v2 — ground-truth pack for the Obsidian-dialect fork

Expected node streams (byte-exact spans + event payloads) for the four
first-class Obsidian extensions this fork adds — block anchors, callout
type/fold fields, embed `!`-folding, wikilink fragments — plus adversarial
cases, over real wiki corpus inputs and synthesized edge files.

**Status: NOT FROZEN.** Freeze gates: (1) Advisor review, (2) re-derivation
of open-question fixtures against the Stream H dialect-conformance spec as
its sections stabilize. The v1 pack (parser-bench `fixtures/`, frozen
2026-07-17) is untouched by this pack; v1 lands separately at `tests/gt-v1/`.

## Layout

```
corpus/        5 inputs copied verbatim from the live wiki (provenance in MANIFEST)
adversarial/   10 synthesized edge files (one ambiguity family each)
               + 2 Stream H probe inputs carried in verbatim (zzprobe-anchors-*)
ground-truth/  <stem>.expected.json — one per fixture, every fixture covered
tools/         derive.py (reproduces expected outputs), verify.py (mechanical invariants)
MANIFEST.tsv   file, sha256, provenance, derivation basis, notes
OPEN-QUESTIONS.md  dialect rulings pending Stream H; re-derive on resolution
```

## Expected-output schema

`{"file": <fixture-relpath>, "schema": "gt-v2", "nodes": [node…]}` — the node
object is wire-contract v1 §5.2 (the frozen sidecar schema: `kind`, `span`,
`text_prefix_16b`, `hpath?`, `unterminated?`, `info?`), with v1's kind enum
and per-kind `info` payloads. Deltas from the v1 ground-truth law:

- **D1 — `info` is asserted.** v1 GT stripped `info`; v2 keeps it. The new
  events are only visible in payloads (callout `{type, fold}`, wikilink/embed
  `{target, heading|block, alias}`), so consumers MUST compare `info` too.
- **D2 — nested callouts are nodes.** v1 law extracted top-level callouts
  only. v2: every quote level whose first line is a callout head is a
  `callout` node. Span = the nested BlockQuote's byte range (starts at the
  innermost `>` of its head line), final line terminator clipped — the same
  clip as every block span. Empirical range source: pulldown offset_iter
  probe at names-contract `eea0453` (OQ-13).
- **D3 — `anchor` nodes gain `info.id`** (the id without the caret), asserting
  the fork's `Event::BlockAnchor(CowStr)` payload. `verify.py` enforces
  `info.id == raw[span.start+1 : span.end]`.

Span laws, ordering law (`span.start` asc, ties `span.end` desc — container
before contained), prefix law, hpath law: wire-contract v1 §2/§5.2,
unchanged. Overlap is intended: inline nodes are also extracted inside block
nodes.

## Derivation method (basis column in MANIFEST)

- `lane@pulldown-0.13.4` — candidate stream generated by the parser-bench
  rust-pulldown lane binary (the de-facto schema wire-contract v1 adopted),
  then audited node-by-node against fixture intent. Prefixes recomputed from
  raw bytes, never copied.
- `+nested-probe@eea0453` — D2 nodes added with byte ranges from a pulldown
  nested-BlockQuote offset probe against the fork at `eea0453` (see
  `tools/derive.py` DELTAS, which records every added node).
- `spec-h:<section>` — derived from Stream H dialect-conformance evidence
  (probe-confirmed vs live Obsidian); supersedes lane basis as sections
  stabilize. First applied: `spec-h:anchors@feed-1` — paragraph-end-only,
  trailing-whitespace-invalidates, table-cell-tails-register (see
  OPEN-QUESTIONS.md Resolved). Where no spec exists yet, lane behavior is
  the documented fallback and every known divergence risk is ledgered in
  OPEN-QUESTIONS.md.

Nothing is invented from memory: every span either came out of a parser run
(lane binary or pulldown probe) and was re-verified by byte-slicing, or does
not exist in this pack.

## Consuming (fork suite)

Compare full node objects — kind, span, hpath, unterminated, **and info** —
in stream order against `ground-truth/*.expected.json`. Fixture bytes are
authoritative: two files deliberately end without a trailing newline
(`anchors-bof-eof.md`, `embeds-chains.md`) and one is CRLF throughout
(`crlf-mixed.md`); do not normalize line endings when loading.

Verify pack integrity: `python3 tools/verify.py` (exits non-zero on any
span/prefix/ordering/manifest violation).

## Freeze protocol

On Advisor approval a `FROZEN` marker (timestamp, sha256 of MANIFEST.tsv,
approver) is added and the pack becomes read-only; post-freeze corrections
follow the v1 pattern — a versioned successor pack, never in-place edits.
Open-question resolutions that land before freeze re-derive in place (basis
column flips to `spec-h:*`); resolutions after freeze go to GT-v3.
